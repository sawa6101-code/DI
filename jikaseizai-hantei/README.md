# 自家製剤加算 算定判定

内用薬マスター検索、算定要件チェック、監査記録を行うPWAです。

## 現在の仕様
- 厚労省の薬価基準収載品目リストから作成した「内用薬のみ」のCSVを読み込み可能
- 商品名・一般名・コード等で検索
- 算定可否は「算定可能（入力条件上）／算定不可／要確認」の3区分
- 粉砕可否は判定せず、判定ロジックにも使用しない
- 監査記録を端末内に保存し、CSV出力
- オフライン利用対応

## 医薬品マスター
厚労省の最新薬価基準収載品目リストから、剤形・区分が「内用薬」に該当する行だけを抽出したCSVをアプリ画面から取り込んでください。CSVの列名に「品名」または「医薬品名」が必要です。コード、一般名、規格、剤形、製造販売会社、薬価の列があれば併せて取り込みます。本リポジトリには全件データはまだ同梱していません。

## 判定ロジックの注意
本版は算定要件確認のための入力支援・監査記録用の初期版です。すべての剤形、処方パターン、例外規定を自動で確定する法的判定エンジンではありません。「算定可能（入力条件上）」は入力チェックを満たした状態を示すもので、請求可否の保証ではありません。最新の診療報酬点数表、留意事項通知、疑義解釈、審査支払機関の取扱い、薬局内規程で必ず最終確認してください。
