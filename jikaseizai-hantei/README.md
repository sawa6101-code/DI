# 自家製剤加算 算定判定

内用薬マスター検索、算定要件チェック、監査記録を行うPWAです。

## 現在の仕様
- 2026年11月12日版の厚労省医薬品マスターから「剤形」コード1（内用薬）を抽出した12,095件を同梱
- 医薬品名・一般名・コード・YJコード・単位・薬価で検索可能
- CSVを取り込むと端末内のマスターを置き換え可能
- 商品名・一般名・コード等で検索
- 算定可否は「算定可能（入力条件上）／算定不可／要確認」の3区分
- 粉砕可否は判定せず、判定ロジックにも使用しない
- 監査記録を端末内に保存し、CSV出力
- オフライン利用対応

## 医薬品マスター
GitHub Actions の `Build internal-use medicine master` ワークフローで、HPDX公開の2026年11月12日版全件マスター（19,324件）から項番28「剤形」コード1（内用薬）を抽出し、`drug_master.json` を生成します。抽出対象は12,095件です。収録項目は医薬品コード、名称、一般名処方の標準的な記載、薬価、単位、薬価基準収載医薬品コード、一般名コード、適用開始日・終了日です。製造販売会社・独立した規格欄は元マスターにないため空欄です。ワークフロー実行後に同ファイルが生成され、アプリに同梱されます。

出典：HPDX「医薬品マスター」 https://www.hpdx.or.jp/seikyushiharai/tensuhyo/kihonmasta/kihonmasta_04.html （2026年11月12日版）

## 判定ロジックの注意
本版は算定要件確認のための入力支援・監査記録用の初期版です。すべての剤形、処方パターン、例外規定を自動で確定する法的判定エンジンではありません。「算定可能（入力条件上）」は入力チェックを満たした状態を示すもので、請求可否の保証ではありません。最新の診療報酬点数表、留意事項通知、疑義解釈、審査支払機関の取扱い、薬局内規程で必ず最終確認してください。
