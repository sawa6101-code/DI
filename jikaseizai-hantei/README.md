# 自家製剤加算 算定判定

厚労省の内用薬マスターを用いて、市販製剤の同一成分・剤形・規格を自動照合するPWAです。

## 市販剤形の自動照合
- 対象薬剤を厚労省マスターから選択
- 製剤後の剤形と規格・濃度を入力
- 一般名処方の標準的な記載から成分キーを抽出
- マスター収載品から同一成分・同一剤形・同一規格の候補を検索
- 一致製剤があれば原則「算定不可（同一市販製剤あり）」
- 同一剤形の候補があるが規格が読めない場合は「要確認」
- 一致製剤がない場合も、マスター照合結果に過ぎず、他の要件を満たすまで算定可とはしない

## マスター
GitHub Actions の `Build internal-use medicine master` ワークフローがHPDX公開の2026年11月12日版全件マスターから剤形コード1（内用薬）を抽出します。収載項目は医薬品コード、名称、基本漢字名称、YJコード、一般名コード、一般名処方の標準的な記載、廃止年月日等です。

## 判定の制限
- マスターの一般名情報が空欄、または一般名・規格・剤形を機械的に確定できない場合は「要確認」とします。
- 一般名処方コードは製剤後の規格・剤形そのものを保証するものではありません。自動照合の一致・不一致は薬価収載マスター上の候補抽出であり、成分同一性、承認規格、剤形区分を薬剤師が確認してください。
- 供給上の問題による例外は、必要数量を確保できなかった事実・理由の確認が必要です。
- 粉砕可否、配合変化、安定性、薬学的安全性は判定しません。
- 「算定要件確認済み（候補）」は入力条件上の候補であり、請求可否の保証ではありません。最新の点数表・留意事項通知・疑義解釈を必ず確認してください。
